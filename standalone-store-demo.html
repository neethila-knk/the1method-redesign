How to Integrate on Any Website

The store uses an adaptive design system that maps directly to your site's CSS tokens.

1. Drop the HTML Section

<!-- Include Scoped Stylesheet --> <link rel="stylesheet" href="css/standalone-store.css"> <!-- Self-Contained Section (Set lang="he" and dir="rtl" for Hebrew) --> <section id="t1m-standalone-store" data-lang="en" data-dir="ltr"></section> <!-- Include Store Engine --> <script src="js/standalone-store.js"></script>

2. Brand it to Match Any Site with 5 CSS Variables

Add this to your website stylesheet to customize fonts and colors instantly:

#t1m-standalone-store { --color-primary: #0b1c30; /* Your brand primary header/dark color */ --color-secondary: #3755c3; /* Your brand button/accent color */ --color-surface-card: #ffffff; /* Product card background */ --font-serif: 'Libre Caslon Text', Georgia, serif; /* Heading font */ --font-sans: 'Hanken Grotesk', sans-serif; /* Body font */ }
